# Калькулятор

Простой и стильный калькулятор с базовыми арифметическими операциями.

## Возможности

- **Сложение** (+) — сложение двух чисел
- **Вычитание** (−) — вычитание чисел
- **Умножение** (×) — умножение чисел
- **Деление** (÷) — деление чисел
- **Процент** (%) — вычисление процента от числа
- **Смена знака** (±) — изменение знака числа
- **Очистка** (C) — сброс калькулятора

## Использование

1. Откройте файл `index.html` в любом браузере
2. Нажимайте кнопки для ввода чисел и операций
3. Нажмите `=` для получения результата
